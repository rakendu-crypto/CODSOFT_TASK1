# README

This project presents the development of a **Network Packet Analyzer** using **Python** and the **Scapy** library. The purpose of this project is to capture, inspect, and analyze network packets in real time. Packet analysis is one of the most important concepts in networking and cybersecurity because every communication that takes place on a network is transmitted in the form of packets. By analyzing these packets, it is possible to understand how devices communicate with each other and identify potential network issues or security threats.

The Network Packet Analyzer captures live network traffic and extracts useful information from each packet. The program identifies the **source IP address**, which represents the device sending the data, and the **destination IP address**, which represents the device receiving the data. It also detects the communication protocol used by the packet, such as **TCP (Transmission Control Protocol), UDP (User Datagram Protocol), and ICMP (Internet Control Message Protocol)**. In addition, the analyzer calculates the packet length and displays any available packet payload data.

The project was implemented using the Python programming language because of its simplicity, flexibility, and extensive support for networking libraries. The **Scapy** library was chosen because it provides powerful features for packet capturing, packet manipulation, and protocol analysis. The development and testing of the project were carried out using **Visual Studio Code** and **PowerShell**.

One of the main advantages of this project is its ability to display packet information in an organized and readable format. Instead of presenting raw network data, the program extracts only the most important information and displays it in a structured manner. This makes the output easier to understand, especially for beginners who are learning the fundamentals of network communication.

This project also provides practical knowledge of how packet sniffing works. Packet sniffing is commonly used in cybersecurity for network monitoring, traffic analysis, troubleshooting, intrusion detection, and forensic investigations. By observing the information contained in network packets, security professionals can identify unusual activities, detect unauthorized access attempts, and investigate suspicious behavior on a network.

Through this project, users can gain hands-on experience with packet analysis and develop a better understanding of network protocols and data transmission. It also serves as an introduction to more advanced cybersecurity tools such as Wireshark, Zeek, and intrusion detection systems. Overall, this project demonstrates the practical application of Python in cybersecurity and highlights the importance of network packet analysis in maintaining secure and efficient communication systems.
